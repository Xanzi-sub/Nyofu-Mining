# Nyofu-Mining

Mining Connect Africa investor platform, built with Next.js, TypeScript, Supabase, and PayFast.

## Local Development

1. Copy `.env.example` to `.env.local` and add the required Supabase and PayFast values.
2. Run `npm install`.
3. Run `npm run dev`.

## Validation

Run `npm run lint` and `npm run build` before deployment.
